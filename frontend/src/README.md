This SmartPlot ZIP's supplied frontend is a static HTML/CSS/JavaScript app.
Its live source files are in ../public (index.html, style.css, app.js, config.js).
The src folders are included as organizational placeholders to align with the repository
layout, but no React/Vite App.jsx or main.jsx was present in the supplied ZIP.
Do not configure this frontend as a Vite/React build unless you first convert it.
